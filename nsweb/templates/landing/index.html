Welcome to Neurosynth.org

Large-scale automated synthesis of functional magnetic resonance imaging (fMRI) data.

What is neurosynth?

Neurosynth is a platform for large-scale, automated synthesis of functional magnetic resonance imaging (fMRI) data.

Neurosynth.org is a legacy application and is no longer maintained.

Active development is focused on Neurosynth Compose, a new platform for running custom neuroimaging meta-analyses with finer-grained control over inputs, models, and reporting.

CHECK OUT NEUROSYNTH COMPOSE

For more information, see the Neurosynth Compose announcement.

Below is a rough roadmap for the neurosynth-compose project.

  1. complete Initial Foundation Users can explore the literature, curate studies, extract the necessary coordinate data and run a meta-analysis using a dedicated user interface that also supports PRISMA compliant workflows
  2. complete MKDA Chi Squared tests Perform large-scale association tests for your custom meta-analyses in Neurosynth Compose
  3. complete Cloud Based Meta-analysis Workflow Aside from running meta-analyses locally, users can take advantage of AWS and Jupyter notebooks to run analyses in the cloud
  4. complete AI Assisted Study Curation Users can take advantage of artificial intelligence to extract study features from the literature
  5. In progress Image Based Meta Analyses Users will be able to use a dedicated interface to complete image based meta-analyses using images from NeuroVault, with features indexed and extracted using Neurostore
  6. Planned Project Cloning Users can clone existing projects and make changes or validate findings
  7. Planned AI Assisted Study Search and other AI Assisted Features Users can take advantage of artificial intelligence to search the literature for relevant studies. They will also be able to get extracted features on an analysis (statistical contrast) level
  8. Planned Pre-seeded Meta-analyses Users can take advantage of pre-seeded meta-analyses to get started with their own analyses, including meta-analyses currently available in Neurosynth
  9. Planned Add support for more Meta-Analysis Algorithms Users can select from a wider range of NiMARE algorithms to run their meta-analyses
